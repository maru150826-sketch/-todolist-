# たろちゃん育成RPG・集中ダッシュボード

学習記録、カレンダー、育成RPGをまとめたWebアプリです。

## GitHubへアップロードする方法

1. GitHubで新しいリポジトリを作ります。
2. このフォルダの「中身」をすべてリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選びます。
5. ブランチを `main`、フォルダを `/ (root)` にして保存します。
6. 数分後に表示されるGitHub PagesのURLを開きます。

最初に開かれるファイルは `index.html` です。

フォルダ構成を変えると画像やRPG画面が表示されなくなるため、そのままアップロードしてください。

## データについて

- 学習記録はブラウザのローカルストレージにも保存されます。
- Supabase同期を使うにはインターネット接続が必要です。
- 激励動画はYouTube埋め込みで再生します。埋め込みが禁止された動画や削除された動画は再生できません。
- 映画や音楽など権利のある動画を公開ページで使う場合は、YouTube側で埋め込みが許可されていることを確認してください。
- 公開リポジトリではSupabaseの接続情報も閲覧できます。匿名キーは公開利用を前提としたキーですが、Supabase側でRow Level Securityを設定してください。
- 現在の同期ユーザーIDは `default-user` です。複数人へ一般公開する場合は、ログイン機能と利用者ごとのID分離が必要です。

## 主な画面

- 本体：学習記録、タスク、タイマー
- カレンダー：日別・週別の学習履歴
- 睡眠：手入力ログ、7日・30日平均、睡眠負債、コンディション、勉強・筋トレ助言
- RPG：IT、TOEIC、HSKの目標、ボス戦、JRPG風スプライト
- 激励動画：本体画面・RPG画面のどちらからでも再生可能
- AI書記：既存の集中時間・タスク・カテゴリ別記録から、今やることを提案

## AI書記

現在の版では、AI書記はメイン画面では読み込んでいません。必要になった場合は `aiSecretary.js` と `aiSecretary.css` を再度 `index.html` に読み込ませることで復帰できます。

過去版のAI書記は、料金のかからないローカル提案だけで動作します。OpenAI APIへ通信しません。

- 提案対象を確認して、そのまま集中タイマーを開始
- 締切・重要度・今日指定・不足分野・時間・体力・過去の評価を点数化
- 「最優先・短時間・不足分野」の3候補を切り替え
- 「元気・普通・疲れた」で推奨時間を調整
- 今使える時間を「10分・25分・45分」から選択
- 締切を「危険・注意・安全」で表示し、期限超過を優先
- タスクごとに予想時間・難しさ・必要体力・次の一手を保存
- 「採用・後回し・微妙」の評価を次回の順位へ反映
- 既存のタスクや履歴は変更せず、書記専用データを別のlocalStorageキーへ保存

## 睡眠ログ

`sleep.html`は外部サービスを使わず、ブラウザ内だけで動作します。

- 睡眠ログ: `sleepLogs`
- 目標睡眠時間: `sleepSettings`
- 寝る前の未確定メモ: `sleepDraft`
- 日付またぎの睡眠時間を自動計算
- 寝る前に「就寝だけ保存」を押すと、朝まで就寝時間が残ります
- 夜モード・朝モードで、寝る前と起床後の入力欄を分けています
- 前回の寝る前チェックを自動で引き継ぎます
- 直近3日不足や大きな睡眠負債があると、睡眠不足アラートを表示します
- CDCの成人睡眠時間・睡眠品質・睡眠日誌項目と、PSQIの考え方を参考にした100点の睡眠スコアを表示します
- 直近7日・30日の平均、睡眠負債、最短日、最長日を表示
- S〜Dのコンディションと勉強・筋トレの助言
- 記録の編集・削除、7日間の軽量グラフ

既存の集中アプリ用localStorageキーは変更しません。
